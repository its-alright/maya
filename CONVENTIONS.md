# Стандарты разработки проекта

## Общие правила
- Писать только чистый, типизированный, production-ready код.
- Никаких заглушек вида `// TODO` или `// Реализуйте здесь`. Код пишется полностью.
- Обязательно покрывать публичные методы XML-комментариями (.NET) или `///` (Rust).
- Текст и рекомендации писать строго на английском языке
- Коммиты, код и все комментарии к нему писать строго на английском языке
- Русский только на входе: описание задачи и конвенции

## Стек: .NET (C# 12+)
- Строгое соблюдение SOLID и паттерна Clean Architecture.
- Использовать современные фичи: primary constructors, collection expressions, raw string literals.
- Обработка ошибок только через Result-паттерн (например, FluentResults) или Exception Middleware. Никаких пустых блоков catch.

## Стек: Rust
- Идиоматичный код (использовать clippy-гайдлайны).
- Строгий контроль Borrow Checker. Избегать `.clone()`, где это возможно, использовать ссылки.
- Никаких `.unwrap()` и `panic!`. Все ошибки пробрасывать через оператор `?` и обрабатывать через `Result<T, E>`.


## Задачи
- Описаны в подпапках корневой папки tasks
- В одной подпапке все требования по этой одной текущей задаче
- Одновременно в работу можно брать только одну задачу
